# AI痕迹自查清单

发布前对照下面的问题清单快速自查，命中越多，AI味越重。

## 开头检查

- [ ] 开头是否用了"在这个……的时代""随着……的发展"这类万能句式？
- [ ] 第一段是否还没有具体信息，只是在铺垫和拔高？

## 结构检查

- [ ] 是否通篇"首先、其次、最后"式的编号推进？
- [ ] 每个分论点的段长是否惊人地一致？
- [ ] 是否有小标题对仗得像对联（字数相等、结构相同）？
- [ ] 全文是不是每个段落都在同一个情绪高度上，没有起伏？

## 语言检查

- [ ] 是否出现三连排比（"不是……而是……更是……"）？
- [ ] 是否频繁使用"值得注意的是""不得不说""值得一提的是"？
- [ ] 形容词是否空洞（"深刻的""独特的""丰富的""极大的"）？
- [ ] 是否有"赋能""闭环""抓手""颗粒度"等互联网黑话混入非行业文本？
- [ ] 动词是否大量被"进行""开展""实现"稀释（如"进行分析"而非"分析"）？

## 结尾检查

- [ ] 结尾是否必来"总而言之""综上所述"？
- [ ] 最后一段是否强行升华到人生、时代、未来的高度？
- [ ] 是否以"让我们一起……"收尾？

## 修改原则

1. 命中3项以内：正常文章，不必强改
2. 命中4至7项：建议对照SKILL.md十种模式逐项修改
3. 命中8项以上：建议保留事实框架，全文重写语言层

## 保真提醒

- 数据、人名、事件、引用来源一律不动
- 只改表达方式，不改事实内容
- 严谨文体（公文、合同、论文）不适用本清单
