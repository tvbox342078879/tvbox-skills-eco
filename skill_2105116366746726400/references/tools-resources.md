## 一、总原则：工具是放大器，不是替代品

| 原则 | 含义 | 反例 |
|---|---|---|
| **工具解决“效率”，不解决“投入”** | 再好的工具也替代不了每天的实际练习 | 装了 5 个背单词 App，每天只点开签到 |
| **工具要与当前水平匹配** | 中级以下用英英词典查每个词，效率极低 | 零基础硬啃英英释义，一天查 3 个词 |
| **工具是分工组合，不是二选一** | 词典管精确、语料库管搭配、AI 管陪练 | “用一个 App 搞定听说读写” |
| **工具的输出必须能被你验证** | 无法验证的工具输出（AI 的语法解释）要交叉核对 | 把 AI 的解释当权威语法书 |

**三件套：怎么做**——先明确你**这一阶段的主攻技能**，只为主攻技能配重工具，其余用最轻的方案维持。**为什么**——工具会消耗时间（挑选、学习、切换），工具越多，真正练习的时间越少，这就是**工具焦虑**的表现形式之一。**坑点**——① 把“找到最好的工具”当成学习的前置条件，两周都在做工具调研；② 迷信单一工具；③ 因工具不够好而放弃学习。

## 二、词典的选择与使用（重点）

### 2.1 词典的六种类型

| 类型 | 英文名称 | 代表品牌（均为真实存在的知名品牌） | 主要用途 | 什么时候用 |
|---|---|---|---|---|
| **双语词典** | bilingual dictionary | 各类英汉／汉英词典 | 快速知道中文意思 | 查名词、专有名词、紧急理解 |
| **英汉双解词典** | bilingualized / semi-bilingual | 由英英学习型词典加中文翻译形成的双解版 | 既看英文释义又看中文对照 | 过渡期使用，可逐步只看英文部分 |
| **英英学习型词典** | learner's dictionary | Oxford Advanced Learner's Dictionary（OALD）、Longman Dictionary of Contemporary English（LDOCE）、Collins COBUILD Advanced Learner's Dictionary、Cambridge Advanced Learner's Dictionary（CALD）、Merriam-Webster's Advanced Learner's English Dictionary | **中高级以上查词的主力** | 想真正掌握一个词怎么用 |
| **母语者词典** | native-speaker / collegiate dictionary | Merriam-Webster's Collegiate Dictionary、American Heritage Dictionary、Collins English Dictionary | 查罕见词、专业词、词源线索 | 学习型词典查不到时补充 |
| **同义词词典** | thesaurus | Roget's Thesaurus、Merriam-Webster Thesaurus、Collins Thesaurus、Thesaurus.com | 找替换词、扩词、辨近义词差别 | 写作时避免重复用词 |
| **搭配词典 / 词源词典** | collocation dictionary / etymological dictionary | Oxford Collocations Dictionary for Students of English、Longman Collocations Dictionary and Thesaurus；Online Etymology Dictionary | 查“这个词常和什么词一起用”“这个词从哪来” | 写作与地道度训练；词根词缀记忆 |

> **补充说明**：以上品牌的具体收词量与内容以官方说明为准。**不要用“收了多少万词条”作为选词典的标准**——你要看的是**释义是否清晰、例句是否丰富、是否标注搭配与语域**。

### 2.2 双语词典的三个坑

| 坑 | 具体表现 | 后果 | 正确做法 |
|---|---|---|---|
| **只看第一个释义** | 查 `last`，看到“最后的”就走 | 遇到 `The meeting lasted two hours.` 完全读不通 | **读完该词性的所有义项**，再看词性标注 |
| **不查搭配** | 知道 `decision` 是“决定”，于是写 `do a decision` | 母语者一眼看出不地道（正确为 `make a decision`） | 查完词义后**专门看一眼例句中的动词搭配** |
| **不看词性** | 把 `access` 只当名词用；把 `record` 的名词、动词重音读成一样 | 写错句子；重音错导致对方听不懂 | **先看词性标注**（n. / v. / adj.），再看每种词性下的释义 |

**其他常见的双语词典使用错误（四个动作）**：① **借还方向搞反**——`borrow` 是“借入”、`lend` 是“借出”，中文一个“借”字覆盖两个方向，这类词必须回看英文释义；② **忽略语域标注**——`kids` 偏口语、`children` 中性、`offspring` 偏正式/书面，不看标注就会在正式场合用错词；③ **忽略地域标注**——如 BrE / AmE 的用词差异（`flat` 与 `apartment`、`lift` 与 `elevator`）；④ **把词典当翻译器**——写中文句子然后一个词一个词查英文，得到的一定是中式英语。

### 2.3 英英词典为什么更重要

| 维度 | 用中文释义 | 用英文释义 |
|---|---|---|
| **信息完整度** | 中文释义是**压缩过的**，只保留核心义 | 英文释义保留**使用条件、典型搭配、语域** |
| **概念对应** | 很多词找不到对应的中文概念（如 privacy、accountability、sophisticated） | 用英文定义英文，保留原有概念边界 |
| **额外输入** | 无 | 查词本身**就是一次可理解输入**，长期是巨大的阅读量 |
| **避免错误映射** | 容易以为“中英一一对应” | 能发现两个词不能互换 |
| **表达地道度** | 倾向于生成中式表达 | 释义本身就在示范地道用法 |

**三件套：**

- **怎么做**：**中级（约 B1）以上，优先查英英学习型词典**；初期可以“先看英文释义、卡住再看中文”。零基础阶段以双语词典为主，等能读懂简单释义再过渡。
- **为什么**：语言学习的核心是建立**“概念 → 英语表达”的直接联结**。中文释义会插入一层中介，导致口语和写作要靠翻译，速度与地道度都受损。这与 `learning-methods.md` 中“用英文理解英文”的思路一致。
- **坑点**：① 把英英词典当“高级感”硬上——**零基础用它只会变成查词典的马拉松**；② 每个词都查英文释义，哪怕已经认识——**只在“要主动使用这个词”时才深查**；③ 只看释义不看例句——释义告诉你意思，**例句才告诉你怎么用**。

### 2.4 查词典的正确流程（四步）

| 步骤 | 做什么 | 关键要求 |
|---|---|---|
| **第 1 步：先猜** | 在语境里猜这个词大概是什么意思、什么词性 | **不要一遇到生词就查**。猜错也有价值：猜错的地方正是记忆最深的点 |
| **第 2 步：再查** | 查词典，**读完该词性的全部义项** | 确认是哪个义项与语境吻合；看词性标注 |
| **第 3 步：记搭配与例句** | 抄下 1–2 个真实例句，标出**常见搭配**（动词 + 名词、形容词 + 名词、介词搭配） | 例句要**完整**，不要只记“词 + 中文” |
| **第 4 步：记语域** | 记下正式度、口语/书面、地域（BrE/AmE）、褒贬 | 语域标错会让表达“对但不得体”（见 `culture-pragmatics.md`） |

**示例（把四步走完一遍）：**

假设读到 `She turned down the offer.`，不认识 `turn down`：

1. **先猜**：从 `offer`（提供的职位/报价）与 `She` 作主语推断，应该是“拒绝了”。
2. **再查**：`turn down` 在词典里作为**短语动词（phrasal verb）** 单列，义项含“拒绝；调小（音量/温度）”。
3. **记搭配**：`turn down an offer / a job / a request`；`turn the volume down`（代词要插在中间：`turn it down`）。
4. **记语域**：`turn down` 偏口语常用；正式书面可考虑 `decline` / `reject`（三者语气与搭配有别，具体以词典标注为准）。

### 2.5 查词典常见问题速查

一直想查词读不下去 → 精读时查，泛读时只在影响理解主干时查；查了记不住 → 因为只记了中英对照，改为**连例句一起记**；不知道查哪个义项 → 按词性 + 语境筛，读完该词性下全部义项；写作时想不出地道搭配 → 用**搭配词典或语料库**，别靠翻译；近义词分不清 → 用**同义词词典**比释义、比例句、比语域；想知道读音 → 用带音频的词典，并看清它标的是英音还是美音。

## 三、语料库（corpus）：查“真实世界里人们怎么说”

### 3.1 什么是语料库

**语料库（corpus，复数 corpora）** 是**大规模、经过整理的真实语言文本/语音集合**，用来观察语言的实际用法规律。常见的大型英语语料库包括 **COCA（Corpus of Contemporary American English，当代美式英语语料库）**、**BNC（British National Corpus，英国国家语料库）** 等，多可在 **english-corpora.org** 这类平台上检索；**COCA 的规模属于十亿词量级、BNC 属于亿词量级**（精确数据以官方说明为准）。

### 3.2 语料库能回答什么问题

| 问题 | 语料库能给出的答案 |
|---|---|
| “这个搭配真的有人这么说吗？” | 直接看到真实例句与出现次数 |
| “A 和 B 哪个更常用？” | 比较两者在语料库中的出现频次量级 |
| “这个说法是口语还是书面？” | 按语体（口语/小说/杂志/新闻/学术）分类查看分布 |
| “这个词常跟哪些动词/形容词/介词一起用？” | 看搭配词排行 |
| “这个句型长什么样？” | 用关键词上下文（**KWIC，key word in context**）观察左右词 |

### 3.3 怎么用（以查搭配为例的操作步骤）

1. **确定要查的词或短语**，例如你想知道 `decision` 前面该用哪个动词。
2. **限定语体**（口语 / 学术 / 新闻…），因为不同语体的搭配习惯不同。
3. **检索该词**，查看 **KWIC 视图**（目标词居中，左右各显示若干词）。
4. **统计目标词**左右两侧的高频伙伴：你会看到 `make a decision` 高频出现，而 `do a decision` 极少；**只看频率量级排序，不看“有没有”**。
5. **与你词典里的例句对照**（两者一致时可信度更高），然后**抄 2–3 条真实例句进语料本**（见第九节）。

> 补充：**AntConc** 是一款可免费使用的语料库分析工具，适合分析**自己整理的小型文本集**（比如你收集的某类外刊文章）；**Sketch Engine** 是功能更完整的在线语料平台，部分功能需注册或付费，**功能与收费以当前版本为准**。

**三件套：**

- **怎么做**：只在**准备主动使用**某个表达时去查语料库，一次解决一个具体问题（“这个词该跟哪个介词”）。
- **为什么**：语料库提供的是**频率与真实分布**的证据，能纠正词典的盲区——词典会告诉你一个用法“存在”，语料库会告诉你它“常不常见、在什么语体里用”。
- **坑点**：① 把“出现过”当“常用”——**低频用法用了会显得怪**；② 不分语体就检索（拿口语语料指导学术写作）；③ 初级学习者过早沉迷语料库——**它的描述性信息对基础阶段的帮助有限，先积累量更重要**；④ 把语料库当翻译工具用，逐词拼句子。

## 四、翻译工具：能用来做什么，不能用来做什么

**常见的机器翻译（machine translation）工具包括 Google Translate、DeepL、Microsoft Translator，以及国内的有道翻译、百度翻译等。它们的功能与收费以当前版本为准。**

### 4.1 可以用于 / 不可以用于

| ✅ 可以用于 | 说明 |
|---|---|
| **快速理解大意** | 读懂一封外语邮件的要点、确认网页说的是什么 |
| **确认词义** | 一个词在句子里到底取哪个义项，机翻可作参考 |
| **生成译文初稿** | 已经有了自己的思路与结构，用它把初稿铺开，再逐句改 |
| **对照学习** | 中英对照看句式差异，观察同一意思的两种组织方式 |

| ❌ 不可以用于 | 为什么 |
|---|---|
| **直接提交作业/论文** | 一旦被判定为机器代写，后果由你承担；且机翻质量不足以通过审阅 |
| **作为学习的替代** | **不查不改地收下译文 = 什么都没学到**，只是搬运 |
| **背诵机翻的句子当素材** | 机翻常违反搭配与语域，背下来会固化错误 |
| **翻译后再回译来验证理解** | 回译结果通常“读得通”，但会掩盖你其实没读懂的结构 |

### 4.2 机翻的典型错误类型

| 错误类型 | 表现 | 例子（示意） |
|---|---|---|
| **搭配错误** | 单个词都“对”，组合起来不地道 | 中文“做出决定”→ 机翻可能给出 `do a decision`（地道搭配为 `make a decision`） |
| **语域错配** | 把口语译成书面语，或把严肃内容译得随意 | 把商务邮件译得像聊天 |
| **习语直译** | 逐字翻译成语 | `It's raining cats and dogs.` 若直译则完全不通 |
| **长句结构崩坏** | 中文流水句改成英文时，主谓宾混乱、从句套层 | 一个长句里出现两个主句、关系代词指代不清 |
| **冠词与单复数** | 该用 `the` 的地方用 `a`，或该用复数用了单数 | 中文没有冠词与单复数，机翻也容易失手 |
| **代词指代错误** | 中文“它/他”混用，译文指代对象错 | 读者无法确定 `it` 指什么 |
| **专有名词与术语误译** | 人名、机构名、行业术语乱译 | 需要以官方译名为准 |

### 4.3 用翻译工具的正确姿势（三步）

| 步骤 | 做法 | 要求 |
|---|---|---|
| **第 1 步：先自己译** | 不看任何工具，凭已有的语言能力写出一版 | 必须写下来，不能只在脑子里过；**这一版就是你真实水平的记录** |
| **第 2 步：对比** | 把你的版本与机翻版本**逐句对照** | 标出三类差异：机翻更好、你更好、两者都错（需要查证） |
| **第 3 步：差异分析** | 对每处差异追问“为什么” | 是搭配问题、语域问题，还是结构问题？**写出结论并记进语料本** |

**三件套：**

- **怎么做**：把机翻当**对照标准**而不是**答案**。差异最大的地方，就是你最该学的地方。
- **为什么**：翻译工具能一次性给出“母语者大致会怎么说”的一个版本，这个版本**比你自己的一版更接近地道表达**，于是差异变成了精确的学习信号。而直接抄译文则跳过了“发现差异”这一步。
- **坑点**：① 先看机翻再看原文——**你的理解会被机翻定型**，读原文时不再自主加工；② 只比“对不对”不比“为什么”；③ 把机翻译文当作“唯一正确解”——**同一句话可以有多种地道说法**，机翻只是其中一种。

## 五、背单词工具：SRS 怎么用才对

### 5.1 SRS 的原理

**SRS（spaced repetition system，间隔重复系统）** 的核心是：**根据你对该条目的回忆表现，动态安排下一次复习的时间点**。遗忘研究通常追溯到 **Hermann Ebbinghaus（赫尔曼·艾宾浩斯）** 在 19 世纪末提出的**遗忘曲线（forgetting curve）**：新学内容随时间快速遗忘，而**在即将遗忘时复习，能显著延长下次的保持时间**。

**这一机制的开创性工程实现是 SuperMemo**（由 **Piotr Woźniak** 开发）；**Anki** 是使用最广的开源实现之一（其调度算法有多个版本）；**Quizlet、Memrise、墨墨背单词、不背单词、扇贝单词**等也提供不同形式的复习机制；**欧路词典**等工具支持加载多种词典文件。**各工具的功能层级与收费方式以当前版本为准。**

**三件套：**

- **怎么做**：把 SRS 工具当作**“复习调度器”**，而不是“学习器”——**先理解、再入卡，然后完全信任它的复习节奏**。
- **为什么**：人无法凭自我感觉判断“这个词我快忘了”。SRS 用你的评分自动算时间点，把复习安排在**记忆即将消退的临界点**，用最少的次数换取长期记忆。
- **坑点**：① **一次加几百张新卡**，两周后复习堆成山，直接弃用——新卡量必须控制在每天能清完的量；② 只点“记得/忘了”而不真正回忆（**自欺式评分**），调度就失真；③ 只认不用——SRS 保证你能**认出**，但**用出来**要靠输出训练（见 `vocabulary-acquisition.md`）。

### 5.2 现成词表 vs 自建词表

| 维度 | 现成词表（考试词表、分级词表、App 内置词库） | 自建词表（从你的阅读/听力/写作里收集） |
|---|---|---|
| **优点** | 覆盖面广、按频率或大纲排序、省事 | 每个词都有**你自己的语境**，记得牢、用得出 |
| **缺点** | 脱离语境、大量词你暂时用不到、容易失去兴趣 | 覆盖面有限、可能漏掉高频词、需要维护 |
| **适用** | 应试冲刺、需要快速扫过大量词的“认识”层 | 应用型学习者、已有一定基础、想提升输出质量 |
| **搭配建议** | 现成词表打底（保证覆盖率） | 自建词表做主力（保证可用性） |

**推荐做法（两条腿走路）**：用现成词表维持覆盖量（每天新词量控制在 20–30 左右，理由见 `vocabulary-acquisition.md`），用自建词表做深度加工（只收**你要用的**词）。

**坑点**：① 完全依赖现成词表 → 背了上千词，写作还是只会那几个；② 完全自建 → 长期漏掉高频词，阅读时到处是洞；③ 两个词表塞进同一个 SRS 牌组 → 新卡量失控。

### 5.3 自定义词卡要记什么（字段设计）

**只记“英文 ↔ 中文”是效率最低的卡片。** 一张有价值的卡片至少包含：

| 字段 | 内容 | 为什么要 |
|---|---|---|
| **正面（提示）** | 不要直接放生词，而是放**一个挖空的真实例句**：`She ___ down the offer.` | 强制在语境中回忆，训练的才是“用” |
| **背面 · 音标** | IPA（国际音标），标注是英音还是美音 | 听力和口语都要靠它 |
| **背面 · 词性与核心义** | 词性 + **英文释义**（可附中文） | 避免中英一一对应的错误映射 |
| **背面 · 搭配** | 该词最常见的 1–3 个搭配 | 搭配是地道的分水岭 |
| **背面 · 完整例句** | 来自词典/语料库/你的阅读材料 | 提供语域与句式示范 |
| **背面 · 语域标注** | formal / informal / spoken / written / BrE / AmE | 避免“对但不得体” |
| **背面 · 你的造句** | 用这个词写一句**与你生活相关**的句子 | 与自身经验挂钩，记忆更牢（“自我参照效应”） |
| **标签** | 来源（哪篇文章/哪次听力）、话题、错误类型 | 便于按主题复习、按错误类型复盘 |

**坑点**：① 卡片信息太多，一张卡要读一分钟——**一次只测一个点**（要测搭配就测搭配）；② 背面直接给中文，眼睛一扫就知道答案，**回忆强度不足**；③ 卡片只进不出，从不归档已经稳定掌握的词，牌组越来越臃肿。

## 六、听力与口语资源类型对比表

> 下表只给**类型与方法**，不指定任何付费课程。所有平台的内容范围与收费以官方当前版本为准。

| 资源类型 | 难度定位 | 适合水平 | 优点 | 坑 |
|---|---|---|---|---|
| **分级听力教材**（如《新概念英语》、各类场景听力书） | 人为控制语速与词汇，逐课递进 | 零基础–B1 | 有配套音频与文本、难度可控、可长期使用 | 语言偏教科书式、内容可能偏旧；**只做教材不接触真实语料，会长期“听不清真人说话”** |
| **慢速新闻**（如 VOA Learning English、BBC Learning English 的教学栏目） | 语速慢、用词受限、常有文本 | A2–B1 | 内容真实、有配套文本、语速友好，是从教材到真实材料的桥梁 | 语速慢是“人为减速”，**长期只听慢速会不适应正常语速**，需逐步过渡 |
| **教学型播客**（如 BBC 的 6 Minute English、ESL Podcast、All Ears English 等） | 以教学为目的，长度短、有讲解 | A2–B2 | 每次聚焦一个话题或表达，碎片时间可用 | 讲解用中文或简单英文时，**容易变成“听中文讲解”**，英语实际接触量不高 |
| **通用话题播客**（如 TED Talks Daily、NPR、BBC 全球新闻类播客） | 接近真实语速，口音多样，话题广 | B1–C1 | 真实语境、可长期订阅、话题可自选（兴趣是最好的驱动力） | 语速快、背景知识门槛高；**不精听则收获很小**；新闻类名词密度高 |
| **YouTube 频道 · 教学类**（如 BBC Learning English、Rachel's English、English with Lucy 等） | 明确定位教学，语速与难度可控 | A1–B1 | 可视口型、有字幕、发音讲解系统 | 易陷入“看讲解但不练”的**学习幻觉**；建议看完立刻跟读 |
| **YouTube 频道 · 知识类**（如 TED-Ed、科普动画类频道） | 真实语速、信息密度高 | B1–C1 | 内容有趣、听英语同时获得知识，动机强 | 画面抢走注意力——**建议先只听截图，再看画面**；专业词汇需另查 |
| **影视剧（sitcom / drama）** | 真实语速 + 大量口语化表达 + 背景音 | B1 以上才有明显效果 | 语料丰富、语用信息（语气、玩笑、讽刺）不可替代 | **本系列反复强调的坑：开中文字幕时大脑自动读中文，英语输入为零**；剧情吸引导致注意力全在情节；俚语与文化梗多，容易挫败。**只精听片段，不整集刷** |
| **有声书（audiobook）** | 单人朗读、语速稳定、无画面 | B1 以上 | 篇幅长、可反复听、可配合文本做“听读同步”；公版书站有大量免费资源（如 LibriVox） | 缺少视觉与语境支撑，**难度比想象的高**；单一朗读者口音单一，需搭配其他材料 |
| **公开课 / 讲座**（如 Coursera、edX、MIT OpenCourseWare、可汗学院等平台上的课程） | 学术语速、结构化讲解、术语密集 | B2–C1，或考前冲刺 | 训练“听讲座 + 记笔记”的应试与学术能力；有习题可验证理解 | 术语与背景知识门槛高；**没有预习与复盘则听不懂** |

### 听力资源使用的三条硬规则

① **精泛分线**：精听用短材料（30 秒–1.5 分钟）走完四步法，泛听只用**已经精听过的材料**或难度明显更低的材料——**不要用泛听啃新材料**。② **难度要有梯度**：教材 → 慢速新闻 → 教学播客 → 通用播客/影视，**不要从教材直接跳到影视剧**。③ **听口一起练**：听力材料就是最好的跟读材料，听完一段立刻跟读一遍。

### 口语练习资源的类型顺序

**跟读音频**（A1 起，零成本，但不录音对比等于无反馈）→ **自言自语 / 独白录音**（无社交压力，但没有外部纠错）→ **AI 对话**（可指定场景与纠错要求，但**不会纠正你的发音**）→ **语伴交换**（真实互动，但对方不是老师，**不约定纠错环节就会长期停在舒适区**）→ **线上口语社群 / 配音活动**（有真实听众、动机强，但质量参差）→ **外教课**（专业纠错、效率最高，**成本也最高，必须带着具体问题去上课**）。方法与反馈机制见 `speaking-training.md`。

## 七、阅读资源类型

> 只用**类型**与**判断标准**选材料，不硬推具体付费课程。所有平台内容与收费以官方当前版本为准。

| 类型 | 适合水平 | 优点 | 坑 |
|---|---|---|---|
| **分级读物（graded readers）** | 零基础–B1 | 词汇与句式**人为控制**，难度阶梯清晰；有配套音频；是最适合建立阅读习惯的起点 | 内容可能偏简化、文学性弱；**长期只读分级读物会停在舒适区**。常见体系品牌有 Oxford Bookworms Library、Penguin Readers、Cambridge English Readers、Macmillan Readers 等（具体分级标准以出版社说明为准） |
| **儿童/青少年分级体系**（如按蓝思 Lexile 或 AR 分级索引的读物） | A1–B1 | 分级精细、题材丰富、可精确选到 i+1 | 内容取向偏青少年，成人可能觉得幼稚；**建议只作过渡，尽快进入成人题材** |
| **外刊**（如 The Economist、The Guardian、The New York Times、The Atlantic、BBC News；国内英文媒体如 China Daily、Sixth Tone 等） | B1–C1 | 语言质量高、题材广、可长期订阅、能积累学术与商务词汇 | 长难句多、背景知识门槛高、**逐词精读会读得很慢**；建议先读标题与首段判断难度的做法为主 |
| **通俗非虚构（popular non-fiction）** | B1–B2 | 语言相对平实、结构清晰、话题有趣；是**从分级读物到原著的关键过渡** | 一本书篇幅长，容易半途而废；建议选薄书、先看目录 |
| **经典原著（classic literature）** | B2–C1 | 语言丰富、句式层叠，是长难句训练的富矿 | **词汇与句式与现代英语差距较大**，不适合作为入门；初期建议只读短篇或对照改写版（retold edition） |
| **学术论文与教科书** | B2–C1 | 训练学术语域、逻辑结构与术语体系 | 术语密集、需要背景知识；**建议先读摘要与结论再决定是否精读** |

**获取渠道类型**（只讲类型）：**公共图书馆的数字资源**（许多馆提供外刊与电子书借阅）、**出版社或媒体的官方 App / 网站**、**RSS 阅读器订阅**（把外刊与播客聚合起来，避免被推荐算法带走）、**学校或机构的数据库**（学术类为主）、**公版书站点**（如 Project Gutenberg 这类站点，适合经典文本，便于复制成语料）。

**三件套：**

- **怎么做**：**同时保持两条阅读线**——一条**泛读线**（材料难度略低、每天 300–600 词、不查每个词），一条**精读线**（短、难、拆长难句）。两条线用不同的材料，避免把一本难书既当泛读又当精读。
- **为什么**：泛读解决**输入量**与**语感**，精读解决**结构性难点**。只用一条线：只精读则速度上不来、量不够；只泛读则难点永远不解决。
- **坑点**：① 一上来读经典原著，每天都在查词——**这是放弃的头号原因**；② 精读时逐个查词，读完一篇用了 2 小时，毫无乐趣——**只查影响理解主干的词**；③ 把外刊当唯一材料，导致口语化表达完全缺失。

## 八、AI 工具的使用边界与风险（重点段落）

**现在可用的对话式 AI 工具包括 ChatGPT、Claude、Gemini、Microsoft Copilot，以及国内的文心一言、通义千问、Kimi、DeepSeek、豆包等。** 它们的能力升级很快，**具体版本的功能与收费以官方当前版本为准。**

### 8.1 AI 适合做什么

| 用途 | 具体怎么用 | 为什么适合 |
|---|---|---|
| **随时对话练习与场景模拟** | 指定场景（点餐、面试、报销沟通）进行角色扮演，并让它追问 | 零社交压力、可无限重复、随时可用 |
| **解释语法** | 让它解释一个句子为什么这样写，并举例 | 能给出即时的结构化说明 |
| **生成例句** | “给我 5 个用 `make up for` 的例句，含不同语域” | 批量获得可控难度的输入 |
| **改写润色** | 把你写的句子让它改成更地道的表达，并说明改动理由 | 差异就是学习点（同第四节翻译工具的三步法） |

### 8.2 AI 的局限（必须知道）

| 局限 | 具体表现 | 应对 |
|---|---|---|
| **不会主动纠正你的发音** | 纯文本对话看不见你的口型；语音模式下纠音通常也不够细 | **发音必须靠录音回听 + 对照标准音频**（见 `pronunciation-phonics.md`） |
| **可能给出“看似合理但不地道”的表达** | 语法成立，但母语者不这么说 | 用**语料库/搭配词典**交叉验证；不把 AI 的句子直接背下来 |
| **可能编造信息** | 编出不存在的词义、例句出处、规则细节 | **不确定就去查权威词典与语法书**，这是硬性习惯 |
| **无法替代真实的语用学习** | 不会真正在意你是否失礼，不会因你的话改变关系 | 语用得体要在**人**身上练（见 `culture-pragmatics.md`） |
| **可能迎合你的错误** | 你说“这样对吗？”它倾向于说“对” | **换个问法**：“这句话有哪些不地道的地方？给出三种替代表达，并说明差别” |
| **对话容易停在舒适区** | 你总是聊熟悉的话题，AI 也顺着你聊 | 主动指定难题材：辩论、投诉、解释专业内容 |

### 8.3 怎么用好 AI（指令设计）

**通用原则：让它给理由、给替代方案、给你能验证的东西。**

| ❌ 差的指令 | ✅ 好的指令 | 差别在哪 |
|---|---|---|
| “这句话对吗？” | “这句话有哪些不自然的地方？给出修改版，并说明每处改动的原因” | 明确要求**指出问题 + 给理由** |
| “给我一些例句” | “给我 5 个 `…` 的例句，分别用于口语、邮件、学术写作，并标注语域” | 可控的难度与语域 |
| “帮我改作文” | “先别改，指出 3 个最影响理解的问题；然后给我一版修改稿，并列出我被改掉的习惯性错误” | 从“要答案”变成“要诊断” |
| “跟我练口语”（直接开始聊） | “扮演面试官，每次只问一个问题，等我回答后，先用一句话指出我的语法或搭配问题，再问下一个问题” | 内置**纠错环节** |

### 8.4 使用 AI 的四个风险

1. **依赖导致自己不思考**：写完句子立刻让它改 → 你失去了“自己判断”的练习机会。**先写完、先自查，再交给 AI。**
2. **把语法解释当权威**：AI 的语法解释**可能有错或不完整**。凡是涉及规则的判断，以**权威语法书与学习型词典**为准。
3. **用 AI 替代真实输出压力**：AI 永远有耐心，因此你永远不会体验“对方没听懂”的窘迫——而**这个窘迫正是进步最快的地方**。建议把 AI 当语伴之前的**过渡与热身**。
4. **把 AI 生成的句子当自己的素材背下来**：你会背到一些**AI 味**的、不地道的表达。要背的是**词典与真实语料里的句子**。

**三件套：**

- **怎么做**：**AI 当陪练，不当老师。** 它的最大价值是提供**随时可用的互动机会**与**快速的对照版本**；一切“权威性问题”回到词典、语法书与语料库。
- **为什么**：AI 的输出质量足够高到有用，也足够不稳定到不能全信。把它放在“**提供练习量与对照参考**”的位置，收益最大、风险最小。
- **坑点**：① 让 AI 替你做作业——你交的是它的水平，不是你的；② 因为一次 AI 给错答案就完全弃用——**正确定位是“陪练”**，它的错误本身也是学习材料（判断它哪里错了）；③ 只和 AI 聊天不做输出训练——聊天不能替代限时写作、复述、听写这些有明确验证标准的练习。

## 九、学习笔记本与知识管理

**核心原则：笔记的作用是“能被复习”，不是“被写下来”。** 写完不复习的笔记等于没写。

### 9.1 单词本（词汇语料本）

| 字段 | 内容示例 | 说明 |
|---|---|---|
| 词条 | `turn down` | 短语动词整体收，不拆开 |
| 音标 | 标注英音/美音 | 用带音频的词典核对 |
| 词性 | phrasal verb | 决定它在句中的位置 |
| 英文释义 | “to refuse or reject (an offer, a request, a person)” | 优先记英文释义 |
| 搭配 | `turn down an offer / a request`；代词需插中间：`turn it down` | **这一栏最容易被忽略，也最重要** |
| 例句 | 抄自词典或你的阅读材料 | 完整句，带语境 |
| 语域 | 偏口语/日常；正式可用 `decline` | 避免“对但不得体” |
| 我的造句 | 与自己的经历相关 | 挂钩自身经验 |

**载体建议**：**用 SRS 工具管理需要长期记忆的条目**（见第五节），**用笔记本/文档管理“按主题成组”的语块与例句**。两者分工：SRS 管“记不记得住”，笔记本管“能不能查得到”。

### 9.2 错题本（错误类型本）

**错题本的价值不在于抄题，而在于“归类”。**

| 字段 | 内容示例 |
|---|---|
| 原句 | 我写的错句：`I very like this movie.` |
| 正确版本 | `I really like this movie.` |
| 错误类型 | **语法/搭配类**：程度副词与动词的搭配（中文“很喜欢”不能直译） |
| 归因 | 中式思维直译 |
| 同类错误还出现过 | `I very want to…`、`I very think…` |
| 纠错动作 | 收集 5 个动词的程度表达（`really like` / `enjoy … a lot` / `be very fond of`）并各造一句 |
| 复现检查日 | 两周后回看，检查是否再犯 |

**三件套：**

- **怎么做**：**按错误类型归类，而不是按题目归类**。每周统计一次“哪一类错误出现最多”。
- **为什么**：语言错误的分布通常很不均衡——**少数几类错误占了大部分**。盯住高频类型（如冠词、时态、介词搭配、中式直译），比反复做整套练习见效快得多。
- **坑点**：① 只抄错句不写类型，一个月后仍是流水账；② 只记“正确答案”不记“为什么错”——**记住原因才能防止再犯**；③ 抄完从不回看，错题本变成考古现场。

### 9.3 语料本（表达素材库）

| 分组方式 | 示例分组 | 适用 |
|---|---|---|
| **按功能** | 表达赞同／委婉反对／提出建议／请求澄清／衔接过渡 | 口语与写作直接可取用 |
| **按话题** | 自我介绍／工作学习／兴趣爱好／旅行／健康 | 口语话题准备（对应 `speaking-training.md`） |
| **按文体** | 学术／商务邮件／日常闲聊 | 语域敏感的场景 |
| **按结构句** | 开头句／转折句／举例句／结论句 | 写作提分 |

**每条素材记三件事**：**整句 + 使用场景 + 语域标注**。轻量、可检索、常回顾。

- **坑点**：① 只抄孤立短语（如 `in terms of`）不抄整句——**用的时候结构会错**；② 语料本无限膨胀从不清理——**只保留真正常用的**；③ 抄了不用——建议每周挑 3 条**强制用进当周的写作或口语里**。

## 十、工具组合方案（按水平与目标）

> 以下只给**类型定位**与**分工**，不含价格信息；所有工具的功能与收费以官方当前版本为准。

### 组合 A：零基础应用型（A1–A2，目标：日常交流）

| 环节 | 工具类型 | 说明 |
|---|---|---|
| 词典 | 英汉双解词典为主 | 前期先看中文，逐步过渡到英文释义 |
| 词汇 | 高频词表 + SRS 工具，每天新词 20–30 | 不背词典；卡片带例句与音标 |
| 发音 | 带音频的词典 + 跟读材料 | **发音优先于一切**，先解决“敢出声” |
| 听力 | 分级听力教材、慢速新闻 | 精听 30 秒起，配文本 |
| 口语 | 跟读 + 独白录音；AI 对话作过渡 | 先解决心理门槛 |
| 阅读 | 分级读物（入门级别） | 每天 300 词，不查每个词 |
| 记录 | 纸质打卡表 + 简单单词本 | 目标是**别断**，不是精化管理 |
### 组合 B：中级进阶（B1–B2，目标：看懂原著、能流利交流）

| 环节 | 工具类型 | 说明 |
|---|---|---|
| 词典 | **英英学习型词典为主**，搭配词典做写作时查询 | 查完必记搭配与语域 |
| 词汇 | 自建词表（来自你的阅读与听力）为主，现成词表补覆盖 | 卡片改成挖空例句形式 |
| 听力 | 教学播客 → 通用话题播客 → 影视剧精听片段 | 精泛分线，泛听不啃新材料 |
| 口语 | 影子跟读 + 复述 + AI/语伴对话 | 约定纠错环节 |
| 阅读 | 双线：通俗非虚构（泛读）+ 外刊（精读） | 每篇拆 2–3 个长难句 |
| 写作 | 仿写 → 段落 → 短文；用 AI 做对照与诊断 | **先自己写，再要诊断** |
| 查询 | 语料库（查搭配与频率）、同义词词典 | 只在“要主动使用”时查 |
| 记录 | 错题本（按错误类型）+ 语料本（按功能分组） | 每周统计高频错误类型 |

### 组合 C：应试冲刺（四六级／考研／雅思托福方向）

| 环节 | 工具类型 | 说明 |
|---|---|---|
| 词汇 | 该考试的官方大纲词表 + SRS；考前做高频词复习 | **以官方大纲与最新公告为准**，不猜题型变化 |
| 真题 | **历年真题**（最重要）；限时模拟 | 每周 1 套限时 + 精析，不贪多 |
| 听力 | 真题音频精听 + 题型专项 | 精听四步法同样适用 |
| 阅读 | 真题精读 + 长难句拆解 | 记录每篇的时间分配 |
| 写作/翻译 | 真题范文对照 + 仿写 + 用 AI 做修改诊断 | **模板只用于结构，不套用整句** |
| 错题管理 | 按题型 + 错误类型统计 | 每两周做一次“分数结构分析”（见 `troubleshooting.md`）；报名时间、题型分值、政策**一律以官方最新公告为准** |

> 关于应试的备考周期与分项策略，见 `exam-preparation.md`。

### 用哪个工具，一句话速查

遇到生词想以后还能用出来 → **英英学习型词典 + 搭配词典**（走完四步）；不确定说法地不地道 → **语料库**（看频率与语体，不看“有没有出现过”）；写完想知道哪里不对 → **AI 要诊断不要答案**；想知道参考译法 → **翻译工具**（先自己译再对比）；要长期记住一批词 → **SRS 工具**（卡片带语境、评分要诚实）；要练发音 → **词典音频 + 录音回听**（AI 不能替你纠音）。
