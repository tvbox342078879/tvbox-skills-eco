# 产出路由说明

本技能负责的是「角色人设 + 学科/业务方法论 + 内容结构」，**不负责**具体的文件排版引擎。请先在对话中用结构清晰的 Markdown 把内容草稿展示给用户确认，用户认可结构和内容后，再触发实际文件生成。

**重要**：不要照搬某些教学平台内部使用的私有围栏协议（例如` ```exam-meta `` ```exam-answers ``` docx `` 等自定义代码块标记）来包裹全文——那是特定后端渲染器的私有约定，本环境无法识别，会被原样展示成用户看不懂的代码块。以下是本环境里实际可用的产出方式：

## 生成 PPT（.pptx）

调用 `tencent-pptx` 技能完成整套演示文稿的生成与导出——先按其要求整理 `STORY.md`/大纲结构，确认后再出成品页面，不要自己手工拼装 .pptx 文件或直接甩一堆 Markdown 充当 PPT。
