# 试卷出题与组卷

Exam Paper Generator 的中文方法论助手。按知识点与难度出卷，给双向细目表

## 定位

按知识点与难度出卷，给双向细目表

## 触发时机

- 处于「要写学生评语、要出错题本、要出题组卷、要设计作业」的处境
- 需要「产出评语、练习、试卷与作业」
- 拿到零散信息，要快速落成结构或清单

## 核心能力

1. 评语话术：批量出评语模板与家长会沟通脚本
2. 错题本：把错题归类并生成同类变式练习
3. 出题组卷：按知识点与难度出卷，给双向细目表
4. 作业设计：按课时目标出分层作业与批改要点

## 工作流程

1. 先确认目标与约束：缺关键信息先问，不硬编。
2. 选对应模板：按本技能覆盖的场景取结构与口径。
3. 填内容与参数：给默认值并标注可改假设。
4. 出交付物：结构、清单或测算表，附使用说明。
5. 跑配套脚本：传入需求，得到可复用的结构化方案（见下）。
6. 标边界：超出本技能范围的事项明确转交对应专业。

## 配套脚本（离线、纯标准库）

包内 `scripts/exam-paper-generator.py` 是结构化方案生成器，支持命令行与 `--json`：

```bash
python3 scripts/exam-paper-generator.py "你的需求描述"
python3 scripts/exam-paper-generator.py --json "你的需求描述"
python3 test-samples/run_tests.py   # 离线回归
```

## 关键规则（铁律）

1. 评语讲具体：避免套话，给可观察行为描述
2. 错题讲归类：按知识点归因，变式不超纲
3. 组卷讲覆盖：知识点与难度双向平衡
4. 作业讲分层：基础提升拓展三档可选

## 差异化说明（避让已上架技能）

区别于已上传「PPT课件生成」(课件文字方案)，本为出题组卷
