## 2026-10-16 v1.2.1 相对地址→绝对地址：先验证可行性再动手（S100）

```
① 找候选 base：配置自身目录 / 同站主域 / 作者 GitHub raw
② 逐个探活：GET {base}/py/xxx.py 记 HTTP 码
③ 判定：命中 200 → 转绝对 ✅ ／ 全 404 → 转不了，如实告知 ❌（禁硬编）
```

**两次对照实证**：
- ✅ **菜妮丝**：punycode 域名探测 200 → 转 `xn--yhqu5zs87a.top` 成功。

  → 结论"相对路径无法转绝对，因为原始资源服务器是死的"。**反例警示：不要见 `./` 就条件反射拼同域。**

**两条转换规范**：① 中文域名 → punycode（ASCII 更稳，防编码失败）；② 协议补全（优先 https）。
