# 去AI味助手 · Skill

把 AI 生成的文字改成"人写的"，检测并修复八类 AI 写作通病。

## 能力

| 通病 | 改法 |
|---|---|
| AI 高频词汇（赋能/抓手/闭环…） | 换成大白话 |
| 过度结构化（僵硬分点） | 能连就连，别全拆成编号 |
| 虚假客观性（众所周知/客观来说） | 删空壳，加具体事实或真实态度 |
| 机械化连接词（此外/然而/因此） | 少用，换自然承接 |
| 完美主义陷阱（每句都太完美） | 允许短句、糙句、口语 |
| 公式化结尾（总之/希望有帮助） | 换成真的收束 |
| 过度修饰（形容词堆砌） | 砍到只剩一个准的 |
| 情感缺失（冷/平/无态度） | 加立场、细节、语气温度 |

**核心原则**：保留原意、不改变事实和语气基调；改出来的文字要像"一个人真的在说话"，有节奏、有温度、有不完美。
