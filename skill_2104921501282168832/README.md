# 去水印

图片、视频的水印都能去。能力按版本陆续上线，下面是现在就能用的，和接下来要上的。

## 现在就能用

**抖音视频：无水印原片**

把抖音的分享链接或整段分享口令发过来，直接存下无水印原片：

- 没有抖音角标，没有抖音号，没有末尾那几秒片尾；
- 不重新压缩，画质就是平台给的原样；
- 默认给哪台电脑都能直接播放的版本，有更清晰的 720p 时会提示你。

**小红书图文：无水印原图**

把小红书笔记的分享链接发过来，每张图都存成无水印原图：

- 没有「小红书」字样；
- 原尺寸，比笔记页面上看到的还清楚，常见三四千像素宽；
- 一条笔记一个文件夹，按顺序编号。

两个平台的东西都自动按作者建文件夹，同一个作者的放在一起。

适合把自己发过的视频、图片，干干净净地再发到 TikTok、Instagram、YouTube 等平台。Instagram 官方说过，带着别家平台水印的内容会被少推。

## 接下来上线

- **画面级去水印**：你电脑里的图片、视频，擦掉烧进画面里的 Logo、文字水印。掌媒科技算法备案完成后开放。
- **小红书视频笔记**
- **抖音图集原图**
- **更多平台**：快手、视频号、B 站
- **批量**：一次发多条链接，一起存

## 使用说明

- Windows 10、11 直接能用，不用装任何软件。
- 给你自己的作品，或者已经拿到授权的作品用。
- 私密、已删除、需要登录才能看的作品拿不到。
- AI 生成内容的标识不擦，这是法规要求。
