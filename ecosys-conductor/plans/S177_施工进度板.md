## 本轮（第 3 步后半）实测修掉的缺陷 · 5 个

### D1 · `tvbox-inspect` M03 backlog 分支 `s` 未定义 —— **最隐蔽的一个**
- 代码：`'item': s[:80]`，而 `s` 在本函数从未定义
- 后果：这条分支**平时永远走不到**（当前无真欠账），M03 一直显示「✅ 执行正常 · 命中 0」。
  **它不是"没欠账"，是从来没真查过。**
- 发现方式：注入一条真欠账 → `NameError: name 's' is not defined`
- 修：`str(item)[:80]`；复验：注入真欠账 → 返回 1 条，内容正确

### D2 · `conductor verify` ① 兜底分支指错方向
- 现象：`❌ ① 探针 45/45：43/45【基线覆盖缺口】`
- 实测 `signal-check` 原文里 `fp_alert`/`base_gap`/`silent_alert` **全为 False**，
  真因是 `pr[0] != pr[1]`（43≠45），却落到 `else '【基线覆盖缺口】'`
- 后果：人照着「基线有缺口」去查，**永远查不到**
- 修：加 `_fail_ids` 解析，兜底改「未通过的源：X,Y」；实测输出 `【未通过的源：4,16】`

### D3 · `signal-check` 有 ❌ 却返回 rc=0
- 现象：屏幕上两行 ❌，`EXIT=0`
- 后果：所有按退出码判断的检查**全假绿**
- 状态：**已登记，未修**（见待办 T1）

### D4 · `activity.py::_hook_state` 把「读不到设置」折叠成「未注册」
```python
except Exception:
    registered = False        # ← 读失败 ≠ 未注册（违反 M-R60）
```
- 后果：settings.json 编码坏/权限改/半截 JSON → 界面一律「❌ 未注册」，
  运维照着去加注册，其实注册一直在。**归因指反了比不报更毒。**
- 修：`registered = None`（三态：True/False/无法判定）
- **连下游一起改**：`activity.py` ③ 段原写 `'✅' if exists and reg else '❌'`，
  `None` 是假值 → 又被折叠回「❌ 否」。**改上游不改下游 = 白改。**
  已改三态显示 `❓ / 无法判定（设置读不到）`
- 实测：好样本 `True True` → 注入半截 JSON → `None None` → 还原 → `True True`
- 实测显示层：损坏时 `❓ … 注册=无法判定（设置读不到）`；还原后 `✅ … 注册=是`

### D5 · `_fold_fp` 指纹把行尾注释算进去了
- 后果：**只改注释、代码一字未动** → 指纹变 → 白名单失配 →
  扫描器把**自己刚登记过**的代码重新报成「未登记新候选」
- 实证：`_fold_fp('registered = None')` = `7d9771fd8e`，
  而扫描器报的是 `60993e233f`（带注释版本）。**两个值不一样，就是它在改注释。**
- 修：`line_text.split('#',1)[0]` 剥注释再算
- 三样本实测：无注释 / 改尾注释 / 缩进不同 → **都是 `7d9771fd8e`**；
  代码真改成 `registered = True` → `47dac850cb`（仍能区分）✅
- 连带：3 条既有白名单因此失配（`raw_n=None`、`_ledger_ok=False`、`sc_cnt=None`），
  补新口径指纹，旧指纹并存平滑过渡

### D6 · 信号源 4 探针 clean 判据把「基线本来就旧」误判成「没清干净」
- 原判据：`clean = not _sig_stale_snap(...)` —— 要求清理后**完全不报警**
- 真相：基线 `history[-1].ts = 2026-10-18`，今天 10-20，按 `age > 1` **本来就该报 2 天未刷新**
- 所以 clean 永远 False。**不是状态残留，是判据把真信号当缺陷。**
- 对照：源 5 / 源 6 都只判**被注入的那个目标**，不因无关真实漂移误判
- 修：clean 改判「注入的 3 天前假 ts 是否已还原成原值」，还原不了才打印「⚠️ 真·清理缺陷」
- 实测：`✅ 信号源4 快照时效：捕获=是 清理后清零=是`

## 判据留档（这次的教训，别下次再犯）

| 检查 | 手法 | 成本 |
|---|---|---|
| 开关真的有效吗 | **同时跑带/不带两种**，比对输出差异（不是看代码） | 2 条命令 |
| 参数真的传到了吗 | `sys.settrace` 在判断行读 `f_locals` | 10 行脚本 |
| 报红时证据还在吗 | **真注入坏样本**，检查证据与退出码同时存在 | 1 次注入 |
| 探针崩了会怎样 | **逐个打坏被测函数**，看条数是否齐、是否点名 | 每个函数 1 次 |
| 改完上游够吗 | **追一遍下游消费方**，看新语义是否被折叠回去 | grep 1 次 |
| 白名单键会不会漂 | **改注释重跑**，看是否失配 | 1 行脚本 |
