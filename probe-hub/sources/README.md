# sources/ — 写源线产物的落点（P018）

**为什么有这个目录**：`livecheck --spider` 能验源，但验完的源原来只落在 `/tmp`，
一次关机就没了。验出来的东西不留档，等于每轮都从零写。

## 命名与留档要求

- 文件名：`<host主域去点>.py`，例 `yyzy_vip.py`（主机 `api.yyzy-tv.vip`）
- 每个源必须能在 `livecheck --spider` 下 5+2 项全过才许留档；不过的不许放进本目录
- 源文件内 `getName()` 写**站点中文名**，不要写「优质」「通用」这类无信息量的名字

## 命令入口（P018 第③项，已解决）

```bash
python3 scripts/probe.py forge verify <文件.py>          # 只验，不落盘
python3 scripts/probe.py forge verify <文件.py> --save   # 过了才落盘
python3 scripts/probe.py forge list                      # 盘点 + 双向对账
```

## 源类型三分法（S162 定稿）——别再把 js 源当 py 源

「直链 / js / py」的分界**不是"来自哪个网站"**（都来自网站），而是：

> **网站返回的东西，TVBox 客户端自己认不认识。**
> 认识 → 直链；不认识 → 要有人帮它翻译，翻译的人是 js 或 python 代码。

| 形态 | 谁在解析 | 客户端需要什么 | 成品库 `源类型` |
|---|---|---|---|
| m3u8 直链 | 客户端自己 | 一条 URL | `m3u8直链` |
| CMS 采集 | 客户端自己 | 一条标准苹果CMS接口 | `CMS采集` |
| **js 源**（drpy2.min.js） | **js 代码** | js 引擎 + 源文件 | `js源码` |
| **py 源**（本目录的 .py） | **python 代码** | py 引擎 + 源文件 | `py源码` |

**关键混淆点**：`drpy2.min.js` 是 **js 版的 py**——工作方式和 py 完全一样（写代码解析），
只是语言不是 python。S162 之前它被当成"py 形态"记在库里，`源类型` 全空，
和 97 条真直链混在一起分不出来。已修正 12 条为 `js源码`。

## 成品源库字段落法（P018 第②项，已定稿）

`体系` 只回答**"要不要 jar"**，不回答"是不是 py"：

| 字段 | 真 py 源取值 | 理由 |
|---|---|---|
| `源类型` | **`py源码`** | 该字段就是干这个的，选项齐备（CMS采集/m3u8直链/js源码/py源码/php源码/JSON配置/XML配置/其他） |
| `体系` | **`直链系`** | 只表达"不需要 jar"。py/js 都不需要 → 都是直链系 |
| `平台形态` | **不填** | 选项集与 `源类型` **完全相同**，是冗余字段；填了两处事实迟早打架 |
| `可进包` | **`需py引擎`** | 与 `需类包` 对称：都回答"缺什么才能跑" |
| `档位` | `未分档` → 测活后按内容分级 | 走现有流程 |
| `随身文件` | 空 | py 源是单文件，无随身 |
| `真实测活` / `测活证据` | `通过` + 七步明细 | forge verify 的结果直接抄进去 |

### `可进包` 三值语义（本条为 S162 新定）

| 值 | 含义 | 客户端要做什么 |
|---|---|---|
| `是` | 直接能进 json | 无 |
| `需类包` | 要 jar 才能跑 | 挂 jar |
| **`需py引擎`** | 要 py 引擎才能跑 | 挂 py 模块 |

> **注意 `可进包` 是 `text` 字段，不是 select**——直接写 `{'text': '需py引擎'}`。

## ★ 写库踩坑：select 字段必须用 `{'select': 值}`，写成 `{'text': 值}` 会静默失败

S162 实测：12 条记录补 `源类型=js源码`，第一次写成

```python
{'源类型': {'text': 'js源码'}}        # ❌ 接口返回 success:true，回读仍是空
```

**接口返回 `{"success": true}`，12/12 全绿，回读却一条都没变。** 换成

```python
{'源类型': {'select': 'js源码'}}      # ✅ 回读确认 12 条已落库
```

才真正生效。

**根因**：`源类型` 在 schema 里是 `select` 类型，写入必须用类型键 `select`；
用 `text` 时平台不报错，只是**忽略**这个值——又一种「success ≠ 落库」。

**正确做法**：不要手写 `{类型键: 值}`，用 `tvbox-source-hub/scripts/build.py` 的
`_wrap(val, spec, field, dropped)`，它读 schema 自动选对类型键，并在值不在
options 内时登记到 `dropped`，不会静默吞。
