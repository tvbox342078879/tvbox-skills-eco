## 三系是什么（1025 口径，判据机读可判）

| 系 | 判据 | 靠什么活 | 测活闸 |
|---|---|---|---|
| **csp 系** | site 的 `api` 为 `csp_*`，或包/站级 `spider` 指向 jar（`.jar`/dex） | **jar 真身**（同枝才可平移，枝=jar md5） | 下载 jar→解 dex→列类名→确认含 `csp_` 后缀同名类 |
| **直链系** | `type=1` 且 `api` 以 `http(s)://` 开头，**零 jar 零 spider**；含苹果 CMS 采集站（JSON/XML 版）与 m3u8 直链 | **直链本身** | 真拉 `vod_play_url` / XML 真拉确认可播 / m3u8 真拉分片 >0 字节 |
| **脚本系** | py 源、drpy js 源（`drpy2.min.js`）、播放页壳、解析器（parses）、判不出者 | 各自宿主环境 | py 五步真跑 / 壳抠链分片>1KB / 解析出流 rounds=3 |

**两条边界**：
1. 三系与 A-E **配置形态**（A=CatVod 标准/B=加壳/C=无jar纯内容/D=Amns/E=待建）**正交不互替**——
   A-E 说「配置文件长什么样」，三系说「每条线路靠什么活」。一份配置包内可同时含三系线路
   （原 L 包就是 csp66+直链36+drpy6 的混包——这正是包口径被废弃的原因之一）。
2. 判不出者落**脚本系**标「待观察」，不硬塞（M-R60）；直送素材站（网页站/网盘）不是线路源，不入三系。

## 为什么「直链系换路线」是一条独立高频动作

- 直链系**零 jar 零 spider** → 换设备/换壳子都不怕，是**最稳的底座**；
- 但直链**会失效**（作者停服 / 换域名 / 防盗链）→ 必须**周期性用新采的活直链替换**；
- 而 csp 系"换内容"是改配置指向（jar 不动），**性质完全不同**——所以直链系需要**独立的一条供料线**。

## 采料 → 换路线 的完整回路（1025 口径）

```
harvest scan/pull   ──►  取回站点/直链候选
        │
        ▼
livecheck.check_auto ──►  真实测活（点播真拉 vod_play_url / 直播真拉分片字节流）
        │                 只留「通过」，失败/无法判定三态如实标注
        ▼
harvest promote     ──►  写入「探源司·成品源库」DB_PROD（拿来即可放进 json）
        │
        ▼
用户据成品源库（直链系线路池） ──►  给任何直链型配置换掉失效线路，补入新活直链
```
