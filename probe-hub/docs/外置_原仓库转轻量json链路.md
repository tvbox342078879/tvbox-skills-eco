### 分叉点（挂载决定论·S113/S113b）

- `http(s)://` 直链 → 保留待测活
- `./py/*.py`、`./js/*.js` 本地相对 → **有 `--base` 则活体探测 200 转绝对保留，否则剔除**（§4.2c 不硬编）
- `csp_*` → **两层判定**：① ext 相对→base 转绝对探测（不通=死）；② spider jar 解 dex 列类名判同名类
  （含=可用 / 不含=死壳剔除 / 下载失败=无法判定≠死保留待人工）；ext 内联 dict 且 jar 含同类 = 可用
- 其他形态 → 剔并记入剔失清单（口径见 §3.5.3「分母不是答案」）

### 五步流水（`harvest lightjson` 内部）

1. **分诊**：按上述分流，非直链类**逐条给原因**（禁静默丢弃）+ 计数汇总
2. **测活闸**：`check_auto` 真实测活，**只留「通过」**；失败/无法判定进剔失清单（无法判定≠死，但不进轻量版）
3. **去重** → 4. **结构**：`{wallpaper, sites:[{key,name,type,api,…}], lives:[]}`；`type` `.m3u8`→**0**（直播）/其余→**1**（点播）；`key=probe-<md5(api|name)[:8]>` **幂等**
5. **命名留档**（规则51）：`<线路系><MMDD>_<描述>.json`（**三系口径 1025**：lightjson 只产直链类，默认前缀 `直链系_`；原 `C` 形态标签降级为 `_note` 里的配置形态信息——配置形态 A-E 与线路三系正交，不再混在命名里）+ 同名 `_剔失清单.json`（**可还原**）
