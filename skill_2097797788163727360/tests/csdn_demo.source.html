本地 AI 字幕工具是怎么搭起来的

给视频配字幕，过去要么按分钟付费，要么把音视频传到别人服务器。本文讲一个纯本地方案。

一、整体流程

抽音轨 → 语音识别 → 文本校对 → 出字幕，全在自己电脑上跑。

  • 抽音轨用 ffmpeg
  • 识别用本地 Whisper
  • 校对用自定义词表

二、关键代码

from faster_whisper import WhisperModel
model = WhisperModel("base", device="cpu")
segs, _ = model.transcribe("clip.mp3")
for s in segs:
    print(f"{s.start:.1f} {s.text}")
形态特点
外挂 srt最通用
软字幕可开关
硬烧不可逆
小提示：硬烧中文若出方块，需指定中文字体文件。
认知增量：双语字幕本质是模型跑两遍识别，耗时翻倍。

收尾：把生成的 srt 拖进剪辑软件即可。
