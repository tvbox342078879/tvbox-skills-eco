# WeChat Markdown Formatter (公众号排版一键美化大师)

This skill converts Markdown syntax into production-ready, beautiful WeChat inline-styled HTML blocks that paste directly into WeChat Official Account editor without formatting loss.

---

## Supported Themes

1. **Classic Emerald (常春藤绿)**: Professional, authoritative business & tech media.
2. **Warm Sunset (暖阳橙红)**: Lifestyle, travel, personal brand, and emotional essays.
3. **Deep Tech Indigo (深空极客蓝)**: Programming, AI tools, developer tutorials.
4. **Minimal Slate (极简雅灰)**: Literary, design, and longform reviews.
